# Language

**Rule.** Talk to the founder in French. Write everything that lands in a repo in English: code, comments, docs, rule files, commit messages, file names. GitHub issue/PR replies are English too (see `github-replies.md`).

**Why.** Founder order: English keeps the public repos readable by everyone and costs fewer tokens; French is only the conversation language.

**How.**
- Reports, questions and summaries for the founder: French.
- In-app copy is not "English only": it is translated into the 11 locales (see `i18n-keys.md`).
