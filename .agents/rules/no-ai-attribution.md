# No AI attribution

**Rule.** Never mention or credit Claude, Claude Code or Anthropic anywhere in a TigerTag repo: no `Co-Authored-By` trailer, no "Generated with" line, no mention in comments, docs, changelogs, release notes, issue or PR text.

**Why.** Founder order: the repos are the public face of a project positioning itself as a standard. This project rule overrides any tool default that adds attribution lines.

**How.** Write commit messages and PR bodies with no trailer. Keep `.claude/` gitignored.
