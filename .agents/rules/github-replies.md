# GitHub replies

**Rule.** Every comment posted on GitHub (issue replies, PR reviews, closing notes) is in English, whatever language the reporter used; posting one needs the founder's order.

**Why.** Founder order (2026-10-12) after a run of French replies on public, international repos.

**How.** Warm and plain (register 2/3 tone), no internal code names, no personal data from the report (an email in a public issue gets removed). Report back to the founder in French.
