## Fixed

- Fixed the remaining time showing **0m** next to the clock in a printer's side card while the printers list showed the correct figure. It affected Bambu Lab and Snapmaker, for two unrelated reasons; both now read the same value the list does.
- Fixed six column headers in the Printers list view (Brand, Name, Model, Status, Job, Last seen) staying in English whatever language the app was set to.

## Security

- Refreshed the dependency tree: 18 advisories (1 critical, 17 high) down to 0. Includes CVE-2026-54673 in `builder-util-runtime`, an AppImage search-path issue in `app-builder-lib`, and three Electron advisories. No configuration changed — the fixed releases were already within the versions this project allows.
