# v2.20.0

## Added

- The scale icon in the top bar now shows **one glyph per scale** (up to two), each coloured by its own state — **green** when active, **blue** in standby, **red** when disconnected, grey when no scale is paired. Hover it for a list with a status dot per scale, so more than two scales are still shown.
- **Standby is now its own state.** A scale with its screen off is fully awake (it just checks in less often), so it shows **blue "standby"** instead of looking disconnected. A scale that has really gone silent still turns red.
- **Battery on the scale icon, iPhone-style** — a little battery with the charge inside: the percentage while on battery, a lightning bolt while charging. Green charging, red when low, neutral otherwise.
- The **Print a TigerPOD** window now offers **two models** — **Standard** and **Mini** (for OpenSpool) — each with its own download.
- The **TigerTag+ material database now holds over 12,000 filaments**, refreshed for this release.

## Changed

- A scale's **Wi-Fi** now shows green while it's connected, with bars for the signal strength — no more red bar on a scale that works perfectly. The exact signal is on hover.
- The **network indicator** only appears when there's an actual connection problem, and only after a few seconds — so it no longer flashes on startup while the app is still connecting.
- The scale **Tare** button now confirms a real success — it turns green only when the scale actually acknowledged, and shows an error otherwise.

## Fixed

- Fixed a scale in standby being shown as offline after 90 seconds.
- Fixed a scale showing "-1 g" for an unknown container weight — it now shows "—".
- Fixed unreadable text on the purple header of the Print-a-TigerPOD window in light mode.
