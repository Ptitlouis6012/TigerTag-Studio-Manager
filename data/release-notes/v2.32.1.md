A fix for Windows computers where the app was extremely slow, and for Google sign-in.

## Fixed

- Fixed an issue where, on some Windows computers, the app was extremely slow: a black window at launch, then a minute or more for each click, even to resize the window.
- Fixed an issue where signing in with Google could fail with a "fetch failed" error on some computers.
