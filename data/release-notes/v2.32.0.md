Ask your AI assistant about your spools, and a Windows launch that no longer freezes.

## Added

- **AI assistants** — let Claude, Cursor or VS Code read your inventory, storage, printers, wishlists and your friends' shared stock, so you can simply ask "what PLA am I low on?". Off by default, turned on per profile in *My profile*, with a one-click install for each app. Read-only: the assistant can look, never change anything, and no password or key is ever shared.
- The app window now reopens at the size and position you left it; the very first launch opens full-size.

## Changed

- Product photos in the cart, lists and wishlists are framed in the product's colour, like in the grid.
- The printer board zoom now stays between 50 % and 100 %.

## Fixed

- Fixed an issue where, on some Windows computers, the app opened on a black window marked "not responding" for several seconds to several minutes.
- Fixed an issue where a downloaded Windows update could fail to install.
- Fixed an issue where a newly added printer was placed at the far left of the printer board, below everything else, or on top of other printers.
- Fixed an issue where the TD value on spool photos was hard to read in light mode.
- The identical-spools counter on grid cards is now a clean circle with its number centred.

## Removed

- The "Colour" column in the inventory, catalogue and favorites tables — the photo frame already shows the colour.
