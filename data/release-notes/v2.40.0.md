Tiger Studio now runs in your browser. Open **tigersystem.io/studio** on any computer or tablet, sign in with your usual account, and your whole stock is there — and you can install it like an app.

## Added

- Tiger Studio in the browser at tigersystem.io/studio (studio.tigersystem.io works too): inventory, storage, lists, catalogue, friends and settings, with the same account and data as the desktop app. Already signed in on tigersystem.io? Studio recognises you.
- Install the browser version as an app: an "Install the app" button in the sidebar on Chrome, Edge and Android; on iPhone and iPad it shows how to add Studio to the Home Screen.
- The browser version always matches the latest desktop release, and an open page switches to a new version by itself.
- Friend links open the Add-friend window in the browser version too.

NFC readers, TD1S, USB scales, printer control and cameras stay in the desktop app for now.

## Fixed

- Fixed an issue where a low-stock alert showed no spool photo on any device other than the computer that created it.
- Fixed an error that repeated in the background every 30 seconds while signed out.
