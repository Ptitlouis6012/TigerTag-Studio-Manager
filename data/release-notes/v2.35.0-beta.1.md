🧪 **Beta — Prusa printers.** This is a test build for Prusa owners. It is not offered as an automatic update: install it by hand from the files below. Feedback is very welcome on [Discord](https://discord.gg/3Qv5TSqnJH) or in the GitHub issues.

## Added

- Prusa printers can now be added to Tiger Studio Manager: MK4 / MK4S, MK3.9 / MK3.9S, Core One, XL (1, 2 or 5 toolheads), MINI / MINI+, and MK3S+ / MK2.5S running PrusaLink on a Raspberry Pi.
- Add a Prusa by scanning your network or typing its IP, then enter the PrusaLink password shown on the printer (Settings → Network → PrusaLink).
- Live status: state, nozzle and bed temperatures, progress, time left, file name and preview, fans, speed and flow.
- Pause, resume and stop a print from the printer card or the printer board.
- MMU: the five slots are shown, with the material and colour the running print uses. XL: one slot per toolhead.
- Camera: a Buddy3D camera is shown once its local RTSP stream is switched on in the Prusa app (enter the camera's own address in the printer settings). A camera connected to PrusaLink on a Raspberry Pi is shown automatically.
- A Prusa that gets a new IP address from your router is found again and reconnected automatically.

## Known limitations

- Prusa printers are reached on your local network only (Prusa Connect is not used).
- PrusaLink does not report which filament is loaded in each slot, so slots only show what the current print expects.
- Prusa cameras do not appear in the detached camera window yet.
- The Prusa logo and printer pictures are placeholders.
