Add your Bambu Lab printers by signing in. Your email, the code Bambu sends back, and every machine on the account shows up — ready to use, from anywhere.

## Added

- Added a third way to add a **Bambu Lab** printer: **sign in with your Bambu Lab account**. Enter your email, type the code Bambu emails you, and every printer on the account appears with its picture — tick the ones you want and add them together. Nothing has to be read off the printer's screen.
- Printers added this way are reached through Bambu's cloud, so they keep reporting when you are away from home, not only on your own network.
- A printer added this way finds its own address and starts its camera by itself when you are on the same network as it.

## Changed

- A printer reached through the cloud now says so: its status dot is a cloud, green when it answers and grey when it does not. This applies to Bambu Lab and Anycubic alike. A machine on your network simply goes silent when you leave the house, while a cloud one keeps answering — so it now takes one glance to know whether something is actually wrong.
- The **+** next to the inventory search is now a filled orange button, easier to find.
- Adding a product no longer accepts a 0 for weight, nozzle and bed temperatures or drying: typing a lone 0 turns it into 1 straight away. Leaving the drying fields empty still means "needs no drying".

## Fixed

- Fixed an issue where a Bambu Lab printer stopped showing anything at all — filament, temperatures, print — as soon as a print failed.
- Fixed an issue where a Bambu Lab printer's AMS was remembered as absent and stayed missing from the board even after restarting the app.
- Fixed an issue where a Bambu Lab print showed no preview picture, and was listed under a file name instead of the project name shown by Bambu's own app.
- Fixed an issue where resizing a camera in the camera view opened or closed that printer's page.
- Fixed an issue where selecting several items and then searching showed a placeholder instead of the warning saying part of your selection is hidden by the filter.
