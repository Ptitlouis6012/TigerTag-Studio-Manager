Bambu Lab fixes, from a user report and a session on real hardware.

## Fixed

- Fixed an issue where editing a filament slot on a Bambu Lab AMS HT applied to the wrong unit — on some setups, to another AMS entirely. Slots on a standard AMS could be affected too, depending on how the printer numbers its units.
- Fixed an issue where the filament window opened without the colour the slot actually holds, so applying without picking a colour wrote black.
- An AMS HT now shows its single spool bay instead of four.

## Changed

- A Bambu Lab printer connected through the cloud now shows only what it can actually do: the light. Everything else it refuses — temperatures, movements, fans, filament slots, pause and stop — is no longer offered. Connect the same printer over your local network to get the full controls back.
