## Added
- Klipper and OctoPrint add flow: the choice card (Scan / Enter IP) now lists the connector's models with their pictures and a search ("Which printer is it?", optional) — the pick carries into the settings form as model + name. - **Demo mode (steps 0–5, open to every user on the desktop app)** — a printer simulator in the main process: one shared print engine per demo printer (heating → leveling → printing → complete → next print, accelerated 20×; pause / resume / stop = cancel; temperature setpoints ramp; colour changes follow the print's slots), a generic print library whose camera picture follows the print (paused freezes the frame, complete shows the finished object), and brand faces that answer the real protocol on a local address so the protocol cores connect unchanged — Klipper (Moonraker, AFC lanes), OctoPrint, FlashForge (AD5X + 4-slot station, serial / access code checked), Prusa (CORE One + MMU3, HTTP Digest), Creality (K2 Plus + CFS: ws 9999, Moonraker 7125, MJPEG 8080, thumbnails on a shared port-80 router that refuses non-local clients) Snapmaker (U1, 4 toolheads, JSON-RPC ws 7125, still camera) and Elegoo in two variants — CC2 + Canvas on an `aedes` MQTT broker (password checked) and CC1 on SDCP v3 WebSocket; the Add-a-printer card lists one row per variant; Bambu Lab (P1S + AMS: MQTT over TLS :8883 with access code, `pushall` / `get_version` / commands, JPEG-over-TLS camera :6000, FTPS :990 file server serving each print's `.3mf` with its plate thumbnail — PASV `0.0.0.0` and no EPSV, as on the firmware) and Anycubic (Kobra 3 V2 + ACE Pro: MQTT over TLS 1.2 :9883, FLV camera :18088 encoded on the fly by the bundled ffmpeg), both LAN only behind a self-signed demo certificate (`services/demo/certs/`) the drivers do not verify. Booth content tooling: `npm run demo:add-print` turns filmed footage into a library print (60 s loop, thumbnail, optional empty-plate / finished-part photos shown before and after the print), and booth events (opt-in) — about one print in three runs out of filament mid-way, pauses with the slot empty, then the spool is swapped and the print resumes. A demo printer prints all the time: the first print starts right away, each next one is drawn at random (never twice in a row), and filament colours are drawn from the app's preset palette (the "Select Color" sheet) — per printer at start-up, and for the slots a print uses at every print and follows the finished one after 4 s; only the user's Stop leaves it idle, Pause holds until Resume. Add-a-printer card shows a *Demo printers* section to every user (one click → a normal record flagged `demo: true` on `127.0.0.1:<port>`, or on a loopback host of its own for the fixed-port brands — macOS creates the missing `lo0` aliases in one administrator prompt), *Demo* tag on the board card and in the side-card title; the simulator starts / stops faces from the account's demo records. macOS measurements (loopback aliases, low ports) and the plan for the other brands in `docs/DEMO-MODE.md`; dependencies `aedes` 1.2.0 (MQTT broker, for the MQTT brands) and `ws` 8.21.3 (now direct, was transitive); `services/demo/prints/**` unpacked from the asar so the bundled ffmpeg can read the videos — `services/demo/{index,engine,library,addresses}.js`, `services/demo/faces/{common,klipper,octoprint,flashforge,prusa,creality,snapmaker,elegoo,bambulab,bambu-ftps,anycubic}.js`, `services/demo/prints/` (4 placeholder prints), `scripts/demo-render-prints.mjs`, `scripts/demo-add-print.mjs`, `main.js`, `preload.js`, `renderer/printers/demo-badge.js`, `renderer/inventory.js`, `renderer/css/40-printers.css`, `package.json`, `CODEMAP-main.md`, `renderer/CODEMAP.md`
  - Adding one: a single "Select a demo printer" row in the brand picker opens a side card with every model of every brand the simulator plays (≈400, grouped by brand, searchable); the pick becomes a demo printer of that model on its brand's own protocol (Elegoo picks CC1/SDCP or CC2/MQTT from the model) — `renderer/inventory.js` (`openDemoPicker`), `renderer/css/40-printers.css`

Changing a demo printer's model rebuilds its machine — `services/demo/{shapes,index}.js`, `services/demo/faces/{bambulab,bambu-rtsp,prusa,flashforge,anycubic,creality,klipper}.js`, `preload.js`
