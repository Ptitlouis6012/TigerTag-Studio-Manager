## Added
- **A reply on one of My requests raises a notification** ("Request #55 got a reply" → opens My requests; the bell counts it) — merged from PR #58 (`renderer/report/replies.js`, `renderer/report/index.js`, `renderer/inventory.js`, i18n `notifReqReply`, `reportMineHint`). Only **team** replies count: the backend's `myReports` now returns `replies` = comments by the repo's owner / members / collaborators, never the app's own account (its "closed by the reporter" note) — so the user's own comments on GitHub are not announced; the client compares `replies` (falls back to `comments` on an older server) and keeps its seen counts under a new key (`tigertag.reportSeen.v2.<uid>`) so nobody's baseline masks a reply.
- **Supporter badge (Ko-fi, Buy Me a Coffee, PayPal).** A payment on any of the three tied to an account gives it a golden-heart **Supporter** badge on the sidebar avatar and a thank-you notification — a thank-you, never a feature. Tied by the account's fixed **supporter code** `TS-XXXX-XXXX` the support menu shows (copy chip: "add your code to your payment message"; derived from the uid so it never changes, unlike the friend code — which still works as a fallback), else by the payer's email; anyone else claims it from the menu ("Already gave? Get your badge": payer email or transaction id). A supporter's menu thanks them instead of pitching.
  - Backend (`TigerTag_Firebase_Backend`): `functions/supportWebhooks.js` — `kofiWebhook` (Ko-fi `verification_token` vs secret `KOFI_VERIFICATION_TOKEN`), `bmcWebhook` (HMAC-SHA256 `x-signature-sha256` vs secret `BMC_WEBHOOK_SECRET`; both BMC payload shapes), `paypalIpn` (PayPal IPN, verified by post-back; completed incoming payments only, note in `memo`) — all record `supportDonations/{source}_{transactionId}` idempotently — and `claimSupport` (ID token; matches an unclaimed payment by lower-cased email or transaction id → `granted`/`not_found`/`taken`); `claimSupport { action: "code" }` returns the supporter code and registers it in `supporterCodes/{code}` (server-only); all set the server-only `users/{uid}.supporter = { since, lastAt, sources, monthly, count }` and, the first time, a `supporter_thanks` notification. `firestore.rules`: `supporter` joins `roles` / `tier` as refused from clients; `supportDonations` has no client rule. README documents both.
  - **TigerSquad** — the Hub's wall of fame, open to everyone, with a level the server computes: **Bronze** (joined for free), **Gold** (gave), **Silver** (20+ TigerTag chips of any kind — `tigerTagCount`) and **Platinum** (gave + 50+ certified) — certified chips are verified server-side with the TigerTag SDK (`certifyChip`, backend), one account per chip, plus **XP points** per physical chip (certified TigerTag+ 10, TigerTag+ 2, TigerTag 1 — twins count twice, TigerData 0) + 50 XP while in the TigerSquad (taken back on leaving), server-counted, published as `tigerSquad.certified` / `tigerSquad.xp` for the Hub's maker ranking and shown under the name in the sidebar as an XP chip for every account ("★ 407 XP", live via a listener on the account doc — `_subscribeOwnSquad`) and in My profile ("407 XP · 19 certified TigerTag+", `_renderSquadXp`; a never-counted account asks `claimSupport { action: "xp" }` once). Join from the **TigerSquad invite** (accounts older than 7 days that haven't joined; 20 s after start-up, once a session; "Maybe later" / ✕ / Esc snooze 30 days per account; leaving the squad lifts the snooze). Redesigned "dark premium": title with a gradient "TigerSquad", three informative perk cards (+50 XP, badges Bronze → Platinum, back the project), each glowing in its own colour (radial light, tinted rim, twinkling sparkles) with a light idle animation (gift hops, badge sways, heart beats; livelier on hover, off under reduced motion), the four levels as large badges on an open strip (no boxed card; big arrows that light up one after the other, left to right, on a loop) with a short motto each, and "Discover the levels →" opening an info bubble anchored to it with the real rules + the XP scale (and a link to the wall of fame; closes on outside click / Esc), an optional coffee card (orange rim + glow, bigger cup, gradient button with a cup icon) that opens the support chooser anchored to its button without leaving the window (Esc / outside click close the chooser first; its "join" row is hidden there), a full-width saturated-orange free-join button (community icon, soft halo) that waits for the real write (loading → "Welcome… +50 XP" or an error), reassurance ticks, "Maybe later", a footer with the live TigerSquad member count bottom-left (`_squadMemberCount`: Firestore REST COUNT over `userProfiles` ordered on `tigerSquad.since`, cached 10 min, hidden when 0 or on error); 700 px / 90 vh with inner scrolling, focus trap + focus restore, 240/160 ms open/close, reduced-motion safe.
