# Worklog — v2.37.1 (in progress)

## Added
- **+5 XP per community link explored** — opening each sidebar link the first time (wiki, Discord, GitHub, MakerWorld, shop, support — the ones with the red "1") earns 5 XP, kept for good; the server reads the click stamps the app already writes (`telemetry/studio.<k>ClickedAt`, or `users/{uid}.<k>Seen`), so earlier clicks count too; new "Community links explored" row in Achievements, dated per link in History — `renderer/inventory.js` (`XP_ACHIEVEMENTS`), backend `functions/supportWebhooks.js` (`COMMUNITY_LINKS`, `ACH_XP.link`; deployed)
- **TigerSquad sound + celebration** — a soft three-note sparkle when the invite appears; joining is an event: a synthesised "legendary" fanfare (low impact, brass-like C–E–G–C climb, swelling major chord, high sparkles) and a ~3 s celebration over the card (the level badge rising out of a burst of light with spinning rays, a shower of sparks, "+50 XP" floating up, the welcome line and the level name; calm under reduced motion); small glassy ticks when hovering the perk cards, the coffee card and the level badges (pitch climbing Bronze → Platinum); hovering "Join" plays a rising shimmer and sends a light running round the button's edge (`_soundJoinHover`, conic sweep on `--tsq-join-ang`); levelling up (Bronze → Silver, … → Platinum) opens a level-up window with the same celebration and fanfare — live when it happens, else at the next launch (last seen level kept per account in `tigertag.squadSeenTier.<uid>`; never on a downgrade) — `_checkSquadLevelUp`, `_openSquadLevelUp`; volumes raised so the cues are heard at a normal system volume — Web Audio, no asset files — `renderer/inventory.js` (`_soundSquadInvite`, `_soundSquadLegendary`, `_soundHoverTick`, `_squadCelebrate`), `renderer/css/10-settings.css`
- **Achievements + History tabs** in the TigerSquad rankings window (next to Countries League and Makers) — Achievements: the total, a **next-level explainer** on top (current badge → next badge, a progress bar for counted rules — 20 TigerTag chips for Silver, 50 certified TigerTag+ for Platinum — what to do, and the action: join / buy a coffee; "Nothing above you but the sky" at Platinum — `_squadNextLevelHTML`), every achievement (earned with its XP and count, or locked with what it is worth and how to get it; discoveries marked "yours for good") ; History: the gains (green) and losses (red) with when and the running total, read from `users/{uid}.xpBreakdown` / `xpUnlocked` and `xpHistory` — `renderer/inventory.js` (`_renderMyXp`, `XP_ACHIEVEMENTS`), `renderer/css/10-settings.css`
- **TD1S recorded on the account** — each TD1S that connects is stored like a TigerSpool: `users/{uid}/td1s/{USB serial}` = { manufacturer, vendorId, productId, firstSeenAt (once), lastSeenAt }; the main process reads the USB identity when it finds the sensor and hands it over on "Sensor connected" (`td1s-device`) — `main.js` (`td1sFind`), `preload.js` (`td1s.onDevice`), `renderer/inventory.js`
- **XP achievements (server)** — XP now also comes from exploring the ecosystem, computed by the backend (`storeTotals`/`achievementParts`): per friend 10, per social link 5, profile photo 10, public profile 5, per connected printer 20, owning a TigerScale 200 / a TigerSpool 75 — all lost again when removed; and one-time discoveries kept for good (`users/{uid}.xpUnlocked`): phone app connected 100, TigerPOD (two readers) 50, first RFID reader 20, first TD1S 30, first rack 10, first list 5. Every change is logged in `users/{uid}/xpHistory` (server-only, owner-readable) with the part, the delta, the count and the new total; `users/{uid}.xpBreakdown` holds the current split. Backend `functions/supportWebhooks.js` (+ triggers `xpFriends`, `xpScales`, `xpTigerSpools`, `xpRacks`, `xpLists`, `xpTelemetry`, `xpTd1s`, `xpPrinters`, `xpProfile`), `firestore.rules`
- **TigerSquad rankings in the app + world rank** — the account menu (click on my avatar) gets "TigerSquad Ranking" for a member / "Join the TigerSquad" (opens the invite) otherwise — both entries stand out: an orange-tinted pill with a bold label a light sweeps across; next to the sidebar XP chip a member gets a rank chip (gold community icon + "#2"); both chips open the rankings (Makers tab; My XP for a non-member); the TigerSquad windows scroll with no visible scrollbar; a member also sees their world rank ("#3 worldwide of 9": 1 + members with more published XP, COUNT over `userProfiles` `tigerSquad.xp`, cached 10 min — `_squadRank`) in My profile, the support menu and the requests card; and a rankings window (`_openSquadBoard`) with two tabs: the **Countries League** (flag, country, members, summed XP, own country highlighted, "France is #1 of 3 countries") and the **Makers** (avatar, flag, level badge, XP, own row highlighted), opening at its final size (fixed height, shimmering skeleton rows during the first load, the last load reused at once on the next open and refreshed underneath), opened from the support menu's member row, the requests card ("See the rankings") or the XP line in My profile; the Hub wall stays one link away — `renderer/inventory.js`, `renderer/report/index.js`, `renderer/css/10-settings.css`
- **TigerSquad flag** — My profile → TigerSquad gains "Countries League": a searchable country picker (flag + name in the app language, the detected country by default) writing `users/{uid}.squadCountry` (ISO alpha-2; cleared = detected). The server publishes `userProfiles/{uid}.tigerSquad.country` (the pick, else the country the app detects) for the Hub's countries ranking — `renderer/inventory.js` (`_fillSquadCountry`, `_setSquadCountry`), `renderer/tz-country.js` (`COUNTRY_CODES`), `renderer/inventory.html`
